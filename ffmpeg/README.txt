이 폴더에 ffmpeg.exe와 ffprobe.exe를 넣으면 시스템 PATH 설치 없이 사용 가능합니다.

배치 방법 1) 직접 넣기:
   ffmpeg/ffmpeg.exe
   ffmpeg/ffprobe.exe

배치 방법 2) bin 서브폴더 사용 (공식 빌드 압축 해제 시):
   ffmpeg/bin/ffmpeg.exe
   ffmpeg/bin/ffprobe.exe

ffmpeg 다운로드: https://www.gyan.dev/ffmpeg/builds/  (Windows)
                https://ffmpeg.org/download.html
